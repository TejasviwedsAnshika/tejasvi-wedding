TEJASVI & ANSHIKA WEDDING WEBSITE

Open index.html in a modern browser. Keep the images folder alongside index.html.
For public sharing, upload the entire tejasvi_anshika_wedding_site folder to a static hosting service.

Features: palace-door opening animation, couple photo gallery with lightbox, rotating CSS 3D-inspired mandap, event filters, countdown, venue map searches, calendar downloads, RSVP message preparation.

Note: RSVP is not connected to a backend; it prepares a message to copy. Venue links open map searches and should be checked for exact pins. Fonts load from Google Fonts when internet is available.

Updated edition: supplied AT Love At First Sight logo added to navigation, hero and footer. Palace gate intro and rotating 3D mandap section removed; original invitation opening flow retained.

RSVP WhatsApp integration: the RSVP form opens WhatsApp to +91 8826276051 with the guest details prefilled. Guests must press Send in WhatsApp; responses are not automatically stored in a database.

Music: A soft original instrumental-style ambient loop is included at audio/royal-wedding-ambience.wav. Music starts after the guest clicks “Unfold your invitation” (browser interaction required) and can be toggled with the Sound button. Keep the audio folder alongside index.html when publishing.
